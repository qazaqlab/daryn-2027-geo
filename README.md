# Мониторинг атмосферных засух Юго-Восточного Казахстана (2010–2025 гг.)

Геоинформационная аналитическая система и интерактивный научный портал для исследования пространственно-временной динамики атмосферных засух на территории Юго-Восточного Казахстана (Семиречье / Жетісу / Северный Тянь-Шань).

Научно-исследовательский проект подготовлен для Республиканского конкурса научных проектов **«Дарын»**.

## 1. Научно-методологическая основа

### 1.1. Параметр атмосферной засухи А.А. Педя ($S_i$)
Оценка засушливости выполнена с использованием индекса Д.А. / А.А. Педя, выражающего разность между нормированной температурной аномалией и нормированной аномалией атмосферных осадков за исследуемый месяц:

$$S_i = \frac{\Delta T_i}{\sigma_T} - \frac{\Delta R_i}{\sigma_R} = \frac{T_i - \bar{T}}{\sigma_T} - \frac{R_i - \bar{R}}{\sigma_R}$$

Где:
* $T_i, R_i$ — фактические средняя месячная температура воздуха (°C) и месячная сумма осадков (мм);
* $\bar{T}, \bar{R}$ — многолетние климатические нормы температуры и осадков;
* $\sigma_T, \sigma_R$ — среднеквадратические отклонения температуры и осадков за исследуемый период.

### 1.2. Градация интенсивности засух
* $S_i \le 0$ — избыточное увлажнение / климатическая норма;
* $0 < S_i < 1$ — слабая атмосферная засуха;
* $1 \le S_i < 2$ — средняя (опасная) атмосферная засуха;
* $S_i \ge 2$ — сильная (экстремальная) атмосферная засуха.

## 2. Наблюдательная сеть метеостанций

В исследовании проанализирован 16-летний хронологический ряд наблюдений (**2010–2025 гг.**) по 5 опорным метеорологическим станциям для каждого месяца теплого полугодия (апрель, май, июнь, июль, август):

1. **Талдыкорган** (область Жетісу, предгорная равнина Джунгарского Алатау, 602 м н.у.м.)
2. **Жаланашколь** (область Жетісу, коридор Джунгарских ворот, 372 м н.у.м.)
3. **Матай** (область Жетісу, Аксуский район, южное Прибалхашье, 391 м н.у.м.)
4. **Алматы, ОГМС** (Северный Тянь-Шань, подножие Заилийского Алатау, 848 м н.у.м.)
5. **Кеген** (Алматинская область, Кегенский район, высокогорное плато, 1802 м н.у.м.)

## 3. Архитектура и функционал системы

* **2D ГИС-карта (Leaflet.js):**
  * Спутниковые снимки высокой четкости Esri World Imagery, топографический рельеф OpenTopoMap, картографическая основа CartoDB.
  * Пространственная интерполяция изолиний засухи методом обратно взвешенных расстояний (IDW).
  * Динамические маркеры станций с цветовой кодировкой текущего индекса $S_i$.
* **3D Цифровая модель рельефа (DEM, Three.js):**
  * Трехмерный гипсометрический рельеф Юго-Восточного Казахстана (хребты Тянь-Шаня, впадина Балхаша, проход Джунгарских ворот).
  * 3D-маяки метеостанций: высота и интенсивность световых колонн пропорциональны индексу $S_i$.
  * Орбитальное управление 360°, масштабирование и фиксированные ракурсы.
* **Интерактивная временная шкала (Timeline):**
  * Выбор года (2010–2025) и месяца (апрель–август) с функцией непрерывного воспроизведения анимации во времени.
* **Аналитический блок (Chart.js):**
  * Графики многолетних рядов $S_i$ с пороговыми уровнями опасности ($S_i = 1$ и $S_i = 2$).
  * Спектральная матрица засушливости («Год × Месяц»).
  * Сравнение климатических норм и радар экстремумов $S_{\max}$.
* **Онлайн-калькулятор модели Педя:**
  * Мгновенный расчет $S_i$ по заданным значениям $T$ и $R$ с визуальной шкалой и математическим разложением формулы (KaTeX).
* **Агротехнический симулятор влагонакопления:**
  * Интерактивная оценка комплекса агротехнических мероприятий (чистые пары, лущение стерни, выравнивание зяби, боронование озимых, питание).
* **Архив базы данных:**
  * Оцифрованные таблицы 1–7 первоисточника с выгрузкой в CSV и JSON.

## 4. Локальный запуск

Проект автономен, не требует сторонних зависимостей Node.js или сборщиков и готов к работе в любом современном браузере.

### Вариант 1. Запуск через Python HTTP-сервер
```bash
# Переход в директорию проекта
cd drought_kazakhstan_science_portal

# Запуск локального сервера
python -m http.server 8080
```
Открыть в браузере: `http://localhost:8080/index.html`

### Вариант 2. Прямое открытие
Открыть файл `index.html` двойным кликом или через контекстное меню любого браузера.

## 5. Публикация на GitHub и GitHub Pages

Для размещения проекта в вашем аккаунте GitHub выполните следующие команды:

```bash
# 1. Инициализация репозитория (если не выполнена)
git init -b main

# 2. Добавление всех файлов
git add .

# 3. Фиксация коммита
git commit -m "feat: initial scientific release of Kazakhstan drought monitoring portal"

# 4. Привязка к вашему удаленному репозиторию на GitHub
# (замените YOUR_USERNAME и REPO_NAME на ваши данные)
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git

# 5. Отправка в ветку main
git push -u origin main
```

### Включение бесплатного хостинга GitHub Pages:
1. Перейдите в ваш репозиторий на GitHub: `Settings` → `Pages`.
2. В разделе **Build and deployment** выберите:
   * **Source:** `Deploy from a branch`
   * **Branch:** `main` / `/ (root)`
3. Нажмите **Save**. Через 1–2 минуты сайт станет доступен в интернете по адресу:  
   `https://YOUR_USERNAME.github.io/REPO_NAME/`
